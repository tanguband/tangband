### 短愚蛮怒とは

　ローグライクゲーム の一種である 変愚蛮怒 の バリアント です

　コンセプトは ”サクサク” ”スピーディー” ”楽しい” 

　変愚蛮怒の楽しさはそのままに、短時間で＊＊＊勝利しなければならないように＊＊＊変更されています

#### プロローグ

「 残された時間は、わずか2週間だ 」

年老いた大魔道士は静かに語った。

「 短愚蛮怒の世界は凄まじいインフレーションの力に包まれている。

　お主がこの世界で得られる経験、金、装備、物資はあちらの世界と比べれば10倍を優に超えるだろう。

　だが、それはサーペントも同様だ。奴はこの世界を終わらせるべく、今も必要なエネルギーを吸収し続けている。

　もう一度言うが、世界の終末までに残された時間は2週間だ。それでも挑戦するかね？ 」

#### 変愚蛮怒からの主な変更点

　ゲーム内で14日間以内にクリアしないと世界の終末イベントが発生する

　キャラクターの成長が10倍速

　高級品やゲーム進行に必要な重要アイテムの出現率が高い

　ユニークモンスターは複数の高級品をドロップしやすい

　序盤のクエストで探索に必要なアイテムが揃う

　辺境の地の宿屋で無料で噂が聞けるため街や鉄獄への移動が簡単に

　スコア送信機能の無効化
